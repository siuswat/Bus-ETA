設定
系統會自動列出每個車站的所有巴士路線。可加入多個車站；KMB/LWB 使用 KMB API；城巴 CTB 使用 DATA.GOV.HK 指定車站 ETA API。
綠色小巴 GMB 詳細加入方法：
1. 先把「巴士公司」選為 GMB。
2. 「巴士站 ID」必須輸入三段格式：路線ID-方向序號-站序，例如：2001227-2-1。
3. 「顯示名稱」可輸入你想顯示的站名，例如：旺角站、小西灣、觀塘碼頭。
4. 「小巴路線編號（顯示用）」請輸入乘客平時見到的路線號，例如：1、16、16A、69A；這個欄位只影響畫面顯示，不會用作 API 查詢。
5. 按「儲存並更新」後，畫面會以你輸入的路線號顯示 ETA。
6. 若顯示不到 ETA，請先檢查三段 ID 是否正確，特別是方向序號和站序。
如何查 GMB 三段 ID：
A. 先試地區路線清單：https://data.etagmb.gov.hk/route/HKI、https://data.etagmb.gov.hk/route/KLN、https://data.etagmb.gov.hk/route/NT
B. 確認地區後，再查指定路線，例如：https://data.etagmb.gov.hk/route/HKI/1
C. 由路線資料找出 route_id 後，再查方向及各站，例如：https://data.etagmb.gov.hk/route-stop/2001227/1 或 https://data.etagmb.gov.hk/route-stop/2001227/2
D. 找到目標站的 stop_seq 後，把三個值合併成：路線ID-方向序號-站序。
地區 region 常用值：HKI、KLN、NT。
唔知道 Stop ID？可到 hkbushub.netlify.app 查詢巴士站 ID。
